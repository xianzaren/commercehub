# Phase 5 完成报告

## 交付范围

Phase 5 已完成 Merchant Analytics & Admin 后端能力：

- 商家分页查询自己的订单和订单详情；
- 订单号、状态、起止时间筛选；
- 商家订单资源所有权隔离；
- `PAID → PROCESSING → SHIPPED` 状态机；
- 商家今日、本月、累计收入、成交订单量和平均订单金额；
- 热门商品销量与收入聚合；
- 可配置阈值的低库存列表；
- 管理员用户、商家、店铺、商品和订单分页查询；
- 用户激活、冻结和禁用；
- 管理员自我冻结保护；
- 管理员强制下架商品；
- 审计日志分页查询；
- 平台用户、商家、店铺、商品、订单与收入汇总。

## 统计口径

销售统计只包含：

- `payment_status=PAID`；
- 订单状态为 PAID、PROCESSING、SHIPPED 或 COMPLETED。

PENDING_PAYMENT 和 CANCELLED 不计入销售额。热门商品基于 order_items 的成交名称、数量和小计快照聚合，因此商品后续改名或调价不会改变历史数据。

今日和本月边界统一按 UTC 计算，与数据库 UTC DATETIME(6) 约定一致。

## 权限与审计

- 商家读取或修改其他店铺订单返回 403；
- 商家不能跳过 PROCESSING 直接发货；
- 未支付、取消或已完成订单不能进入商家处理流程；
- 管理员不能冻结自己的当前账户；
- 用户状态变更、商家订单状态变更、商家审批/冻结和商品强制下架均记录 before/after JSON、操作人、实体与时间。
